# signContent, cultureNotes, signClips

- `itemKey(item)` = `sign:<GLOSS>` (curriculum spelling, upper case: `sign:THANK-YOU`, `sign:DON'T-LIKE`),
  `letter:A`, `number:7`. It's persisted in `weak_signs.item_key` (same regex as the DB check), so **never change the
  format**. `itemFromKey` is the inverse. Unlike recognition's internal key, it is not normalized (`THANKYOU`):
  curriculum.ts is the one spelling.
- `signInfo(item)` returns label, meaning, handshape and clip:
  - `meaning` covers Unit 1 signs only so far, and is null for letters and numbers.
  - `handshape` is null everywhere. Notes must come from fluent signers, so none are written here.
  - `clip` is read from `signClips.ts` (`SIGN_CLIPS`, itemKey → `{ videoId, start, end }`). That file is generated by
    the coordinator's YouTube search script. Today it's an empty stub.
- `cultureNotes.ts` holds the culture notes by lesson id (Unit 1: 1.1, 1.2, 1.4). They are all `draft: true` and need
  review before they count as final. curriculum.ts attaches them as `lesson.culture`.
